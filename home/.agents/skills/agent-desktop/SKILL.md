# agent-desktop

Before operating a desktop app, load the installed CLI's version-matched guides:

```bash
agent-desktop skills get desktop
agent-desktop skills get platform
```

Follow those guides for permissions and the observe, act, verify loop. Load
references on demand with `agent-desktop skills get desktop <reference>`;
use `agent-desktop skills list` to discover other guides.
